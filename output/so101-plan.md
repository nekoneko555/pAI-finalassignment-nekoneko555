# SO-101拡張の作業方針

対象は実機ではなく、SO-101のMuJoCoシミュレーション。ユーザーの追加要望を反映し、完成範囲を「A地点の物体へ近づく、つかむ、持ち上げる、B地点へ運ぶ、離す」へ変更した。日本語による動作条件の変更も含む。

1. **モデル導入と動作確認**: MuJoCo MenagerieのSO-101をコミット固定で取得する。ライセンス・出典・ファイルハッシュを保存し、実際の関節を動かした動画を出す。
2. **環境とテスト**: アーム5関節とグリッパーを使用し、物体をMuJoCoの自由剛体にする。物体の座標を移動中に書き換えたり、溶接拘束で固定したりせず、指との接触・摩擦で運搬する。成功は両指での把持、持ち上げ、B地点への移動、解放と静止まで確認する。GymnasiumとSB3の環境チェック、決定性、入力検証、描画を確認する。
3. **基準制御とPPO**: IKが経由姿勢を作り、状態機械が開閉順序を決める。PPOはIK追従を基準として各関節の速度を最大±35%補正する残差制御を学ぶ。把持全体をゼロから学習したとは説明しない。IKだけ、ランダム補正、未学習PPO、学習済みPPOを比較する。2関節版の重み・成功率は流用しない。学習128配置・検証30配置・最終評価100配置を分離し、検証で選んだ重みを最終評価前に固定する。
4. **言語統合と提出映像**: 実LLMが指示を解釈して同じ重みの動作条件を変える。日本語の目的説明、同じ目標での動作比較、全試行の集計、限界を1〜3分にまとめる。

ローカルCPUで開始し、まず処理速度を測る。有料GPUは自動起動しない。クラウドを使う場合もユーザー指定の1時間1ドル以下・L40優先を守る。

比較実験ではモードを明示指定して制御性能を測り、言語解釈の結果とは分ける。成功例だけから成功率を算出しない。慎重モードは速度を下げる設定であり、接触ゼロや実機安全を保証しない。

最初の動作確認では、IKによる8.68秒の把持・運搬・解放を実測した。物体中心の最大高さ0.0652m、最終B地点誤差0.0116m、両指と接触した状態での持ち上げを検出した。この1ケースを一般的な成功率とは扱わない。動作映像はvideos/so101_pickplace_ik.mp4。

既存の2関節版・動画・評価結果・提出ZIPは保存する。SO-101成果物は専用の名前・ディレクトリへ出力する。今回の移行は、見た目だけを差し替えて既存の性能を主張するものではなく、新しい環境として検証する。
